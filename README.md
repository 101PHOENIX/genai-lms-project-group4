# Magerit Highschool — Backgrounds

11 individual AI-generated 2.5D anime visual novel room backgrounds.

- Intended Unity location: `unity/Assets/Art/Backgrounds/`
- Format: JPG (opaque), mostly 1600 x 900, 16:9 (pool image 1600 x 899).
- Rooms: gym, cafeteria/kitchen, chemistry lab, swimming pool, greenhouse, computer lab, library, student dormitories, infirmary, dance room, chapel.
- Room artwork should be imported in Unity as Sprite (2D and UI) if used as sprite-based backgrounds.
- Generated images may have small inconsistencies; review before release.
